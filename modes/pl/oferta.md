# Tryb: oferta — Pełna ocena oferty

> This file is a localization wrapper. It does not define an independent evaluation workflow.

## Authoritative execution contract

Before evaluating a posting, read and execute `modes/oferta.md` in its current
version. Also load `modes/_custom.md` when present, `modes/_profile.md`, and this
locale's `_shared.md`. Retain every root gate and output requirement, including
API-first liveness, bounded current research, source-bound factual claims, A-G
evaluation, configured scoring/caps, atomic report-number reservation, the report
Machine Summary, and canonical tracker persistence.

Use this locale's `_shared.md` for regional vocabulary and conventions, and write
candidate-facing responses in Polish. Localization may change language and regional
terminology only; it must never change liveness, research limits, scoring, source
boundaries, report numbering, persistence, application authorization, review, or
submission behavior.

This evaluation wrapper may draft report Section H answers when the canonical root
workflow calls for them. It never opens or fills a live application; selected live
applications always use root `modes/apply.md` plus `modes/_custom.md`,
`queue-resolve.mjs`, and `application-receipt.mjs`.

If any copied instruction, README, historical handover note, or prior agent summary
conflicts with `modes/oferta.md`, ignore the stale copy and follow the root workflow.
